# 🎛️ Techno Prompt Studio v12 Master Arranger

Ein interaktives Generator-Tool für KI-Techno-Prompts, das speziell auf **Suno AI**, **Udio** und **Midjourney** abgestimmt ist. Es bietet dynamische Instrumenten-Anpassung, DJ-Signature-Presets, Song-Arrangement-Tools sowie eine integrierte Web-Audio-Synthesizer-Vorschau.

---

## 🇩🇪 Deutsch

### 🌟 Hauptfunktionen
* **Dynamische Instrumenten-Anpassung:** Wähle aus über 40 DJ-Presets (z. B. *Charlotte de Witte*, *Klangkuenstler*, *Stephan Bodzin*, *Sara Landry*). Das Studio stellt Synthesizer, Drums und Vocals automatisch passend zum Genre/Künstler ein.
* **Multi-AI Support:** Generiere maßgeschneiderte Prompts für:
  * **Suno AI** (Style-Tags & Formatierung)
  * **Udio** (Beschreibender Text-Prompt)
  * **Midjourney** (Cover-Art Prompt)
* **Arranger & Timeline:** Aktiviere oder deaktiviere Song-Abschnitte (`[Intro]`, `[Build-Up]`, `[Main Drop]`, `[Breakdown]`, etc.) für eine präzise Song-Struktur.
* **Web-Audio Synthesizer Engine:** Höre dir mit der integrierten Audio-Preview und dem Frequenz-Visualizer direkt im Browser ein Klangbeispiel an (303 Acid, Moog, 909 Drums).
* **MIDI-Export:** Exportiere das aktuelle Pattern als `.mid`-Datei für deine DAW.
* **Titel- & Lyrics-Generator:** Erstelle auf Knopfdruck zufällige Techno-Tracktitel und passende Lyrics in mehreren Sprachen.

### 🚀 Schnellstart
1. Lade die Datei `index.html` herunter.
2. Öffne die Datei mit einem beliebigen Browser (keine Installation erforderlich).
3. Stelle deinen gewünschten DJ-Style ein und klicke auf **Prompt Generieren**.

## 🇬🇧 English

### 🌟 Key Features
* **Dynamic Instrument Mapping:** Choose from over 40 DJ Signature presets (*Charlotte de Witte*, *Klangkuenstler*, *Stephan Bodzin*, *Sara Landry*, etc.). The studio automatically updates synthesizer, drum, and vocal engines to match the selected style.
* **Multi-AI Engine Support:** Generate optimized prompts for:
  * **Suno AI** (Style tags & structured formatting)
  * **Udio** (Descriptive natural-language prompt)
  * **Midjourney** (Album cover art prompts)
* **Full-Track Arranger:** Toggle structural blocks (`[Intro]`, `[Build-Up]`, `[Main Drop]`, `[Breakdown]`, etc.) to guide the track structure.
* **In-Browser Web Audio Engine:** Preview sound patterns with a real-time Web Audio API synthesizer (303 Acid, Moog, 909 Drums) and visualizer.
* **MIDI Export:** Export generated patterns as `.mid` files directly into your DAW.
* **Title & Lyrics Generator:** Generate random techno titles and arranged lyrics across multiple languages.

### 🚀 Quickstart
1. Download the `index.html` file.
2. Open it in any modern web browser (no installation or server needed).
3. Select your DJ preset or customize settings, then click **Generate Prompt**.
